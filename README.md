# Learn GenAI

A practical learning repository covering **Generative AI, LLMs, RAG, AI Agents, LangChain, and LangGraph** through hands-on examples and projects.

## Topics

* Prompt Engineering & LLMs
* LangChain
* RAG & Vector Databases
* LangGraph
* AI Agents & Memory
* Voice Agents
* Hugging Face

## Setup

```bash
git clone https://github.com/isanjeevroy/learn-genai.git
cd learn-genai

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

Create a `.env` file and configure the required API keys.

## Structure

The repository is organized progressively, from **LLM fundamentals to advanced GenAI applications**, with each folder containing focused examples and implementations.

> Built for learning, experimentation, and practical GenAI development.
